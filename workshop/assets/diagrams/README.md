# Diagrams

Each `*.drawio.svg` file is a normal SVG image (the site and GitHub show it as is) with the draw.io diagram embedded in it.

To edit one, open the file in draw.io (desktop app, app.diagrams.net, or the VS Code "Draw.io Integration" extension), change it and save. Keep the `.drawio.svg` name so the diagram stays editable.
