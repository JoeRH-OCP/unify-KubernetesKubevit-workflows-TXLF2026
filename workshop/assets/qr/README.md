# QR code for the lab sheet

The Module 1 slide shows `lab-sheet.png` from this folder. Until the file exists, the slide shows an empty "QR" box.

Save the QR code of the Google Sheet link (the participant sheet described in the instructor guide) as `lab-sheet.png`: a square PNG, at least 600 x 600 px, black on white. Check that the sheet is shared as "Anyone with the link can edit" before printing or projecting it.
